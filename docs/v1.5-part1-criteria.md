# Cadence v1.5, Part 1: acceptance criteria

Re-read after every step. A box is ticked only with evidence (a command output, a measurement, or a snapshot), noted next to it.

## Build
- [ ] `cargo build` passes
- [ ] `cargo clippy` passes with no new warnings against the step 0 baseline

## Design language and motion
- [ ] `ui/tokens.slint` exists; no hardcoded colours or loose px / ms values remain outside it (grep is clean, allowing only `0px` and unitless viewbox numbers)
- [ ] Shared `Button`, `IconButton`, `Card`, `SectionHeader`, `ListRow` shell exist with default, hover, pressed, focused and disabled states
- [ ] All animations use the token durations (120 / 200 / 320 ms) and easings
- [ ] Nothing animates while idle: no running timers, no animation tick, CPU near zero over 5 minutes

## Loading
- [ ] Launch shows cached Liked Songs, playlists and Home immediately
- [ ] Background refresh updates in place with no flicker and no scroll jump
- [ ] Cache files contain no tokens and no Client ID; writes are atomic
- [ ] Liked Songs (1000) and playlists (1000) scroll smoothly with no spinner and no blocking
- [ ] One shared HTTP client; identical in-flight requests deduped; 429 honours Retry-After; capped backoff otherwise

## Art
- [ ] Art for visible rows loads first
- [ ] Cached art appears instantly; new art fades in over the placeholder
- [ ] No image decoding or HTTP on the UI thread
- [ ] `pick_image` used everywhere art is shown; 64 px source never used above row size
- [ ] Mini player cover is sharp at 100 %, 125 % and 150 % display scaling
- [ ] Every `Image` uses `image-fit: cover` and smooth scaling

## Memory and renderer
- [ ] Every cache is bounded and evicts; channels bounded; abandoned tasks aborted
- [ ] Memory plateaus at idle, after 3 scrolls of 1000 liked songs, after 20 playlists, after 30 minutes; numbers reported
- [ ] One of femtovg / skia kept, with comparison numbers reported

## Icon
- [ ] Icon source moved to `assets/icon-source.png`; no copy left in the repo root
- [ ] `assets/cadence.ico` has all 9 sizes (16, 20, 24, 32, 40, 48, 64, 128, 256), each rendered separately, 256 stored as PNG
- [ ] 16, 20 and 24 px versions are legible (three arcs distinct)
- [ ] Icon is visible on both a dark and a light Windows taskbar
- [ ] New icon in the in-app header, window and taskbar, `.exe`, media flyout and README; old icon gone (grep is clean)
- [ ] Generation script under `scripts/`
- [ ] "Icon by Icons8" credit in the README footer

## Scope
- [ ] Part 2 to 5 items untouched: search ranking, TrackRow / play-button behaviour, autoplay, updater, Client ID setup, login and token storage, version number

## Manual tests
- [ ] Launch cold and warm
- [ ] Scroll Liked Songs end to end quickly
- [ ] Open 20 playlists one after another
- [ ] Mini player at 125 % scaling, cover checked
- [ ] Resize the window
- [ ] Idle 5 minutes, CPU near zero
- [ ] Taskbar icon and window title bar on a dark and a light Windows theme
