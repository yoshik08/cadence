# Cadence v1.5, Part 1: design audit and token map

What was hardcoded in `ui/*.slint` at v1.4 (`4dfbf77`), and what each value became. Counts are
from a search of the v1.4 files; `theme.slint` (the old token file) is excluded.

## What was found

| Kind | Count at v1.4 | Where most of it was |
|---|---|---|
| Hex colours | 77 uses, 39 distinct values | `lyrics.slint` (43), `mini.slint` (17), `now_playing.slint` (5), `widgets.slint` (4), `dialog.slint` (4) |
| Font sizes in px | 23 uses, 8 values (9, 10, 11, 12, 13, 14, 15, 17) | `lyrics.slint`, `mini.slint`, `widgets.slint` |
| Corner radii in px | 42 uses, 15 values (1 to 24) | everywhere |
| Animation durations | 17 uses, 8 values (120 to 500 ms) | `lyrics.slint` (12), `side.slint`, `browse.slint` |
| Easings | CSS `ease`, one cubic-bezier, and `Theme.ease` | `lyrics.slint` |
| Other px literals (sizes, offsets, spacing) | about 570 lines | every file |
| Private copies of shared components | 5 buttons (`Pill`, `TransportButton`, `PlayDisc`, `CloseButton`, mini `Btn`), 3 `Label`s, 2 `Glyph`s, 2 icon buttons (`IconButton`, `RoundIcon`), 2 text buttons | `lyrics.slint`, `mini.slint`, `queue.slint`, `menu.slint`, `now_playing.slint`, `widgets.slint` |

After the migration `python scripts/lint_tokens.py` reports 0: no hex colour and no px / ms
literal outside `ui/tokens.slint`, except `0px` and the value of a named property declared at
the top of the one component that uses it.

## Spacing, radii, motion

| Scale | v1.4 | Now |
|---|---|---|
| Spacing | 4, 8, 12, 16, 24, 32, 48 plus loose 1, 2, 5, 6, 7, 10, 14 | 4, 8, 12, 16, 24, 32, plus `space-2xs` 2 for the gap between a row's two text lines. 48 was unused and is gone. |
| Radii | 1, 2, 2.5, 3, 4, 6, 8, 9, 10, 11, 12, 14, 16, 18, 19, 22, 24, 999 | 4, 8, 12, full. Thin bars and circles use full; 6 to 11 became 8; 12 to 16 became 12. |
| Durations | 120, 150, 200, 220, 300, 350, 400, 500 ms | 120 (fast), 200 (base), 320 (slow) |
| Easings | `ease`, two cubic-beziers | `ease-out` for hover and enter, `ease-in-out` for movement |

Page changes fade and slide 8 px (was 16 px over 220 ms).

## Sizes

Shared across components, so in `tokens.slint`: icon 12 / 16 / 20 / 24, control height
32 / 36 / 44, row height 36 / 52 / 68, art 56 (thumbnail) / 160 (card) / 176 (header), 4 px
track, 1 px hairline, sidebar 232, side panel 340, bottom bar 88, page margin 32.

Used by one component only: a named property at the top of that component (for example the
mini player's 72 px cover, the lyrics page geometry, the track table's column widths).

Merges that moved pixels: icons 14 / 15 became 16, 18 became 20, 22 became 24; controls
28 / 30 became 32, 34 / 38 became 36, 40 became 44; library and queue thumbnails 48 / 52
became 56.

## Components

| Shared (`ui/base.slint`) | States | Replaces |
|---|---|---|
| `Button` (primary, secondary, ghost, danger) | default, hover, pressed, focused, disabled, active | `PrimaryButton`, `SecondaryButton`, the dialog's own OK button |
| `IconButton` (square or round) | default, hover, pressed, focused, disabled, active | `IconButton` (bar), `RoundIcon`, mini `Btn`, lyrics `TransportButton`, lyrics `CloseButton` |
| `ListRow` | default, hover, pressed, selected, focused, disabled | the hand-written row backgrounds in the sidebar, library, track table, queue, menu, search history, stats |
| `Card` | default, hover, pressed, focused, disabled | menu, dialog and overlay surfaces |
| `SectionHeader` | default, hover, pressed, disabled (action link) | `SectionTitle`, settings group titles, panel titles |
| `Label`, `Caption`, `Glyph` | | three private `Label`s, two `Glyph`s, the bar's `Icon` |

Keyboard focus is opt-in per instance (`focusable`), and nothing opts in yet, so Tab and Enter
behave exactly as in v1.4.
